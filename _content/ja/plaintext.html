PlainText+

プレーンテキストのまま、ちょっと便利に。

PlainText+ は、VS Code の拡張機能です。新しい記法を覚えたり、プレビューと行ったり来たりすることはありません。書いたテキストの行の頭に記号を置くだけでアウトラインになり、登録したキーワードや会話文は自動でハイライトされます。

主な用途

メモ、日記、小説など

主な機能

  • アウトライン：行の頭の記号（【、▼、■ など）から、すぐにアウトラインを作ります。階層にもでき、Sticky Scroll にも対応しています
  • ハイライト：キーワード、行、コメント、囲み記号を、柔軟に飾れます。入れ子の囲みにも対応しています
  • 辞書補完：「@」を入力すると、登録した言葉を候補に出して入力できます
  • ナビゲーション：次・前のアウトラインの項目へジャンプするコマンド
  • 折りたたみ：アウトラインの項目ごとに折りたためます。「現在位置以外を折りたたむ」コマンドもあります

使い始める

VS Code の拡張機能の画面で「PlainText+」を探してインストールし、アウトラインとハイライトの設定を settings.json に足します。設定のサンプルは、Marketplace のページにあります。
